# Cloud Digest — актуальные метрики после повторного аудита Golden set

Дата: 7 ноября 2026. **Статус: DRAFT, не подтверждено независимым редактором.** Это пересчитанные диагностические метрики, а не финальная accuracy новой модели.

## Что проверено

- Полный поток Brand Analytics за 31 августа: **169** сообщений; текущий бренд-фильтр выделяет **154**.
- Повторно проанализированы все 169 записей, **27** меток релевантности изменены, **60** требуют приоритетного просмотра.
- Для независимых новостей, комментариев, собственного контента Cloud.ru и репостов созданы отдельные типы. Из набора предварительно подходят для внешней ленты **102** публикации; **30** отмечены только как распространение, а не самостоятельные новости. Эти классы не являются автоматически подтверждённой истиной.
- В `gold/2026-08-31_reaudit_DRAFT.json` сохранены **154** метки для штатного оценщика (dev: **127**, test: **27**). Вся совокупность 169 записей — в Excel.

## Привязка к бренду и тональность

Оценка по предварительным `brand_gold`: TP=145, FP=9, FN=15, TN=0; Precision **94,16%**, Recall **90,63%**, F1 **92,36%**. Совпадение тональности BA с предложенными `tone_gold`: **139 из 160**, или **86,88%**. Эти показатели **не менялись** после аудита, поскольку соответствующие метки не были скорректированы. Это согласие с предложенной разметкой, не независимое подтверждение точности BA или Cloud Digest.

## Что пока нельзя заявлять

- Отсутствуют реальный прогон `semantic` по обновлённому Golden set и сравнение его качества с baseline.
- Из 169 строк **0 подтверждены независимым редактором**, `review_status=draft`.
- Разметка несбалансирована: **126** сообщений об одном финансовом сюжете, в основном `dev`.
- Нет помеченных критических случаев (`critical=true`); кризисный Recall не вычисляется.
- Требуется отдельный независимый контрольный набор иных дат и типов событий.

## Как воспроизвести

```cmd
python -m cloud_digest.evaluate_cli --input "partner_data\Очищенная выгрузка 26-31.08.json" --partner-export --date 2026-08-31 --gold "gold\2026-08-31_reaudit_DRAFT.json" --output "results\evaluation_reaudit_baseline.json"
```

Для semantic потребуется установленная и реально запущенная модель embeddings, а также отдельно подтверждённая редактором разметка. Пороги нельзя подбирать по контрольной части.

Источники: `Cloud_Digest_Golden_Set_REAUDIT_data.json`, `Cloud_Digest_gold_REAUDIT_DRAFT_for_evaluator.json`, `Cloud_Digest_REAUDIT_baseline_evaluation.json` и код `cloud_digest.evaluate_cli`.
