# Проверка датасета

В каталоге находятся анализ, требования и независимое ревью. Это завершенный этап проверки входных данных; он не означает завершение доработки программы.

Исходные шесть файлов не включены в Git. Укажите путь к разрешенной локальной копии:

```powershell
python docs/dataset-review/profile_data.py --source-dir "C:/path/to/dataset" --output "profile.json"
```

`profile.aggregate.txt` содержит JSON с агрегатами проверенной версии. Расширение `.txt` позволяет сохранить агрегаты при запрете публикации произвольных JSON в `.gitignore`. Результат скрипта можно сравнить с этим файлом. Он не содержит текстов сообщений, идентификаторов людей или реальных URL.

Пути `artifacts/runs/...` в исходных отчетах относятся к локальному рабочему пространству проверки. Для воспроизведения из Git используйте команду выше. Проверено 510 записей и 30 эталонных карточек. Независимый профиль совпал побайтово. Набор не является доказанно обезличенным и не подтверждает производственное качество.
