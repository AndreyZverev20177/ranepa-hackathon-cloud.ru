# Delivery: воспроизведение и оставшийся объём

1. Установить Python 3.11+ и пакет по [README](../README.md).
2. Запустить JSON-demo с `--synthetic`: получить четыре карточки и маркированные JSON/TXT.
3. Повторить с CSV-demo: содержимое результатов должно совпасть.
4. Просмотреть `review_queue`, объяснения скоров, `risk_alert` и исходные выдержки. Никакие PR-действия не выполняются.
5. Запустить команды проверок README. Проверки backend: 18 unittest, mypy, compileall и wheel пройдены на синтетическом входе; это не метрики точности.

Golden 80–120 карточек и сценарии тихого (80–200), шумного (400–900), кризисного (300–700 сообщений) дней остаются требованиями будущей проверки. Датасетов сейчас нет и они не входят в текущий объём. До оценки качества нужны согласованные критерии разметки и эталон, затем измерения; заявлений о достигнутой точности нет. Внутренние интеграции BA/модели, инфраструктура и редакторский UI также впереди. Bootstrap не является финальной сдачей хакатона.
