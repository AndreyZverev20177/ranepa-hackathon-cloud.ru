# Состояние проекта и воспроизводимость

## Что есть в репозитории

Работающий локальный прототип Cloud Digest: обычный/партнёрский входной JSON/CSV, предобработка, две кластеризации, три режима скоринга, источник top-25, история распространения, TXT/JSON, вспомогательный RSS-отчёт, инструменты оценки и тесты. Для использования семантики требуется опциональная ML-модель. Есть локальный прототип веб-панели на Streamlit с просмотром сюжетов и сохранением редакторских правок. БД, планировщика и промышленной интеграции с Brand Analytics пока нет.

## Приёмка перед демонстрацией

1. Из корня проекта поставить пакет: `python -m pip install -e .` (для ML: `python -m pip install -e ".[embeddings]"`).
2. Выполнить `python -m unittest discover -s tests -v`; убедиться в `OK`.
3. Запустить baseline на demo и Story Score на одной из выгрузок; открыть `results/...json` и `results/...txt`.
4. Для семантической версии отдельно проверить скачивание и инференс модели на своей машине, затем корректность групп в нескольких сюжетах.
5. Проверить все сомнительные пары и кризисные сигналы с редактором. **Не сообщать о достигнутой precision/recall по всему потоку** до независимой разметки.
6. Перед публикацией/демо обезличить или исключить партнёрские данные и ссылки, если это требуется соглашениями о доступе.

## Контрольные особенности

| Компонент | Статус | Что пока необходимо |
|---|---|---|
| Инжиниринг и регрессионные тесты | Есть | CI на целевой версии Python, проверка сборки |
| Индивидуальный скоринг | Есть, эвристика | Калибровка весов и редакторская валидация |

| Продуктовый MVP | Частичный локальный UI | Настоящий feedback loop со скорингом, API, БД, роли, безопасность, мониторинг |
