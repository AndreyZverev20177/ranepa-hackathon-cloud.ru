# Cloud Digest Editor — исправление загрузки и скачивания (UI 1.1)

Этот патч **не изменяет** кластеризацию, формулы Publication/Story Score, адаптер Brand Analytics и редакторский журнал.

## Обновлённые файлы

- `ui/app.py` — отдельная загрузка исходных датасетов; после обработки открывается **новый** дайджест; вверху кнопки скачивания JSON, TXT и одного ZIP.
- `src/cloud_digest/dataset_upload.py` — распознавание исходной схемы, проверка расширения/UTF-8/структуры, безопасное сохранение загруженной выгрузки.
- `tests/test_dataset_upload.py` — тесты загрузки, ошибок ввода и работы CLI.
- `docs/DASHBOARD.md` — описание загрузки и скачивания.

## Как поставить

Распаковать архив в **корень** проекта `outputs\\repo`, сохранив структуру каталогов, с заменой `ui/app.py` и `docs/DASHBOARD.md`.

```cmd
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
RUN_DASHBOARD_WINDOWS.bat
```

Если сервер уже открыт, обнови вкладку браузера (Streamlit обычно автоматически перезагружает приложение после изменения `.py`).

## Использование

1. Открой **Сформировать новый дайджест → Загрузить свой датасет** и выбери файл `.json` или `.csv`.
2. Выбери дату, `story-v1`, при необходимости embeddings. Нажми **Обработать выгрузку**.
3. Новый результат откроется на странице. Вверху нажми **Скачать всё ZIP** (либо **Скачать JSON** или **Скачать TXT**). Браузер сохранит его в настроенную папку загрузок.
4. Исходные и обработанные файлы **уже сохраняются** локально в `results/ui/uploads/` и `results/ui/.../` соответственно. Для разных датасетов и режимов создаются разные папки.

## Какие пользовательские файлы поддерживаются

- **Исходный JSON Brand Analytics:** JSON-массив публикаций с `id`, `timeCreate`, `url` и прочими полями исходного экспорта BA.
- **Нормализованный JSON Cloud Digest:** массив записей со столбцами/ключами `message_id`, `published_at`, `source_type`, `source_name`, `url`, `text`.
- **Нормализованный CSV Cloud Digest:** те же обязательные шесть столбцов, UTF-8. Можно подготовить свой датасет в этих столбцах.
- **Готовый digest-*.json:** загружать **отдельно**, в поле «Загрузить готовый дайджест». Он не проходит повторно через движок.

Не поддерживается любой произвольный табличный CSV с нестандартными колонками: потребуется настроить отображение столбцов или расширить адаптер входных данных. Максимальный размер загружаемого датасета — 30 МБ.

**Почему не сохраняется автоматически в "Загрузки":** приложение работает как локальный сервер. Оно не может по своей воле менять папку загрузок браузера. Нужен явный клик по кнопке скачивания. В `results/ui/` файлы сохраняются автоматически после обработки.

**Безопасность:** пользовательские выгрузки остаются на локальном ПК (при локальном запуске), не отправляются в BA. Файлы в `results/` исключены из Git через `.gitignore`. Если открываешь панель по сети, доступ к ней нужно защитить.
