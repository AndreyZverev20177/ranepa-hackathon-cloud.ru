# PATCH — Cloud Digest Editor (Streamlit)

Данное обновление содержит **только новые и изменённые файлы** и применяется поверх последней версии Cloud Digest (после этапа 08 и ревью репозитория). Не содержит партнёрских выгрузок, результатов и кэшей.

## Установка

1. Сделай резервную копию репозитория или commit в Git.
2. Распакуй архив в корень проекта (папка с `pyproject.toml`) **с сохранением путей** и заменой README, pyproject.toml и docs.
3. Открой CMD в корне репозитория:

```cmd
.\.venv\Scripts\python.exe -m pip install -e ".[ui]"
RUN_DASHBOARD_WINDOWS.bat
```

Для запуска режима embeddings из панели установи `.[ui,embeddings]` вместо `.[ui]`.

В браузере: **http://127.0.0.1:8501**.

Если виртуального окружения ещё нет:

```cmd
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[ui]"
```

## Проверка

```cmd
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

В сборке патча: **142 теста проходят**; исходная бизнес-логика и веса скоринга не менялись.

В `partner_data/` оставлена старая структура. В интерфейсе можно выбрать существующий `digest-*.json` или сформировать `story-v1` за дату из партнёрской выгрузки. Не обязательно включать embeddings для демонстрации.

## Ограничения

- Код страницы проверен на синтаксис; полноценный браузерный запуск **не протестирован здесь**, поскольку `streamlit` не удалось установить из-за отсутствия доступа к пакетному репозиторию.
- Редакторский журнал локальный, для одного пользователя: `artifacts/editor_reviews.json`. Он игнорируется Git.
- Изменённые тональность и связь с брендом добавляются в **редакторский экспорт**, но не пересчитывают баллы модели и не отправляются обратно в Brand Analytics.
- Предложение разделить/объединить сюжеты сохраняется как запрос редактора; сам состав кластеров не меняется.
- Прямой доступ к API BA требует отдельного контракта и разрешений; см. `docs/DASHBOARD.md`.
