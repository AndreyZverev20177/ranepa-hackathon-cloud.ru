# Обновление документации Cloud Digest Editor

Этот патч **не меняет Python-код, скоринг или интерфейс**. В нём только `README.md` с расширенной пользовательской инструкцией для UI 1.1.

## Установка

Распакуй `README.md` в корень репозитория `outputs\repo`, где лежат `pyproject.toml` и `RUN_DASHBOARD_WINDOWS.bat`, с заменой старого README. Перезапуск Streamlit не требуется.

## Что добавлено

- Запуск через `.venv` и открытие локальной панели.
- Различие между исходным датасетом и готовым дайджестом.
- Поддерживаемые JSON/CSV, ограничения форматов и размера.
- Пошаговая обработка, фильтры, карточки, очередь, правка редактора.
- Скачивание JSON/TXT/ZIP, расположение локальных результатов.
- Диагностика типовых ошибок и границы интеграции с Brand Analytics.
